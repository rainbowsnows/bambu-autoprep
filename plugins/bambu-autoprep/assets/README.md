# Bambu reference project

`p2s-0.4-pla-basic.3mf` was generated by the official Bambu Studio 02.08.02.61 Linux release. It is an unsliced 10 mm cube used solely as a native-format template; the exporter replaces its geometry and writes selected process settings.

Profiles: Bambu Lab P2S 0.4 nozzle, 0.20mm Standard @BBL P2S, Bambu PLA Basic @BBL P2S. Plate: Textured PEI Plate. Machine, temperature and G-code defaults are preserved. There is no account, printer address or credential in this template. No G-code/toolpath file is bundled.

Upstream release: https://github.com/bambulab/BambuStudio/releases/tag/v02.08.02.61

The corresponding original profiles (including inherited/included fragments) are retained in `vendor-profile-source/`. They are upstream Bambu data, covered by the accompanying `BambuStudio-LICENSE.txt` (AGPL-3.0). This repository's own code remains MIT licensed. Do not remove the source or attribution from redistributed archives.

Generation: flatten the original profile inheritance and include fragments, then run official Bambu CLI with `--load-settings machine.json;process.json --load-filaments filament.json --arrange 1 --ensure-on-bed --export-3mf reference.3mf cube.stl`, without `--slice`. Set the actual plate field to Textured PEI Plate.

Validation: the generated ghost project reopened in official Bambu Studio, exported its settings with every chosen override retained, and generated a nonempty sliced G-code archive. Tests did not connect to or start a physical printer. Validation artifacts are temporary and are not included in the plugin.
